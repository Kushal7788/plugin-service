# Verifier Service API Reference

Base URL defaults to `http://localhost:7047` for local service runs.

The current Cloudflare Worker custom domain is
`https://mpc-verifier.burnt.com`.

## OpenAPI Schema

`GET /openapi.json`

When deployed behind the Cloudflare Worker, returns the OpenAPI 3.0 schema for
the public API without starting or routing to a verifier container.

## API Docs

`GET /docs`

When deployed behind the Cloudflare Worker, returns a Swagger UI page backed by
`/openapi.json`.

## Health

`GET /health`

Returns `ok` when the process is running.

## Info

`GET /v1/info`

Returns service name and API version.

## Register Session

`POST /v1/sessions/register`

```json
{
  "sessionId": "optional-worker-minted-uuid",
  "clientSessionId": "sample-session",
  "maxRecvData": 65536,
  "maxSentData": 65536,
  "sessionData": {
    "allowedRequestHeaders": "[\"accept\"]",
    "allowedResponseBodyJsonPaths": "[\"user.name\"]"
  }
}
```

`sessionId` is optional. When provided, it must be a UUID and must not already
exist. This lets a Worker mint the session ID before routing registration to a
named container instance. When omitted, the service generates a UUID.

Returns `sessionId` and `verifierWsUrl`. `verifierWsUrl` is a relative
WebSocket endpoint path; resolve it against the same origin used for
registration, with `ws` for `http` and `wss` for `https`.

## Verifier WebSocket

`GET /v1/sessions/{sessionId}/verifier`

The prover connects to this endpoint with WebSocket upgrade. Binary and text
frames are bridged into the TLSN verifier runtime.

## Reveal Config

`POST /v1/sessions/{sessionId}/reveal-config`

Accepts the reveal ranges generated by the plugin. The service rejects response
headers and response body paths outside the session allowlist.

## Issue Attestation

`POST /v1/sessions/{sessionId}/attestation`

```json
{
  "attestationRequestB64": "<bincode attestation request as base64>"
}
```

Returns:

```json
{
  "attestationB64": "<bincode attestation as base64>"
}
```

## Session Result

`GET /v1/sessions/{sessionId}/result`

Returns `pending`, `in_progress`, `completed`, or `failed` plus transcript
digest metadata when completed.

## Artifact Verify

`POST /v1/artifacts/verify`

Accepts the plugin proof artifact and verifies payload shape, trusted notary
policy, and presentation signature.
