# Verifier Service API Reference

Base URL defaults to `http://localhost:7047`.

## Health

`GET /health`

Returns `ok` when the process is running.

## Info

`GET /v1/info`

Returns service name and API version.

## Register Session

`POST /v1/sessions/register?host=localhost:7047`

```json
{
  "clientSessionId": "sample-session",
  "maxRecvData": 65536,
  "maxSentData": 65536,
  "sessionData": {
    "allowedRequestHeaders": "[\"accept\"]",
    "allowedResponseBodyJsonPaths": "[\"user.name\"]"
  }
}
```

Returns `sessionId` and `verifierWsUrl`.

## Verifier WebSocket

`GET /v1/sessions/{sessionId}/verifier`

The prover connects to this endpoint with WebSocket upgrade. Binary and text
frames are bridged into the TLSN verifier runtime.

## Reveal Config

`POST /v1/sessions/{sessionId}/reveal-config`

Accepts the reveal ranges generated by the plugin. The service rejects response
headers and response body paths outside the session allowlist.

## Issue Attestation

`POST /v1/sessions/{sessionId}/attestation`

```json
{
  "attestationRequestB64": "<bincode attestation request as base64>"
}
```

Returns:

```json
{
  "attestationB64": "<bincode attestation as base64>"
}
```

## Session Result

`GET /v1/sessions/{sessionId}/result`

Returns `pending`, `in_progress`, `completed`, or `failed` plus transcript
digest metadata when completed.

## Artifact Verify

`POST /v1/artifacts/verify`

Accepts the plugin proof artifact and verifies payload shape, trusted notary
policy, and presentation signature.
